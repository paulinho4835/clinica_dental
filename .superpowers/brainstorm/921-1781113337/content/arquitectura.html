Mapa de archivos — qué se toca

NUEVO
lib/agenda/doctorColor.ts
Hash determinístico doctor id/nombre → índice de paleta. Exporta getDoctorColor(id) → {bg, border, text}. Paleta de 8 colores fijos.
NUEVO
lib/agenda/dragDrop.ts
Lógica pura de pointer events: useDrag() hook. Recibe blockGeometry, devuelve handlers y estado de drag. Sin JSX.
MOD
components/agenda/WeekView.tsx
Usa getDoctorColor() en cada bloque. Integra useDrag(). Muestra ghost-slot destino. Optimistic update → revert en error.
MOD
components/agenda/DayView.tsx
Mismo color-por-doctor y drag que WeekView. Bloques más altos, muestra motivo + CI cuando el bloque tiene espacio suficiente (altura > 48px).
MOD
components/agenda/MonthView.tsx
Reemplaza badge contador por pastillas de nombre. Hasta 2 pastillas + "+N más". Puntito de color del doctor en cada pastilla.
MOD
components/agenda/apptHelpers.ts
Agrega apptBlockClass(status) que devuelve clases Tailwind para estado (no cambia el color base, que ahora viene del doctor).
SIN CAMBIO
lib/agenda/index.ts · blockGeometry · assignLanes · dentistColumns
La matemática de posicionamiento no cambia — ya funciona bien y el drag la reutiliza.

Interfaz del hook useDrag()

draggingId: string | null

ID de la cita en vuelo. null = nadie se arrastra.

ghostSlot: {date, time} | null

Slot destino actual. El componente renderiza el ghost con este dato.

dragHandlers(apptId)

Devuelve { onPointerDown, onPointerMove, onPointerUp } listo para spread en el div del bloque.

isDragging(apptId)

Devuelve true si ese bloque está siendo arrastrado (aplica clase CSS "dragging" = sombra elevada + scale).

Restricciones y decisiones de diseño

🔒
Sin drag cross-day en Vista Semana v1 — arrastrar entre columnas de días queda para v2. En v1 solo se arrastra dentro del mismo día (evita complejidad de mutación de fecha).
🔒
Clic-arrastre para crear solo en Vista Día — en Vista Semana los slots son demasiado estrechos para un drag de creación usable. Vista Semana: clic simple abre el modal.
📐
Snap a 15 minutos — STEP_MIN = 15 ya definido en DayView. El hook lo usa directamente.
📐
getDoctorColor es pura y determinística — el mismo doctor siempre obtiene el mismo color en cualquier render, sin necesidad de contexto o estado.
♿
Accesibilidad mínima v1 — los bloques conservan role="button" y aria-label existentes. Keyboard nav y screen reader completo queda para v2.
